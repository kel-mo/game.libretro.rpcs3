# Sony - PlayStation 3 (RPCS3)

### Description

A port of the RPCS3 PlayStation 3 emulator to libretro. It runs the Cell processor with RPCS3's LLVM recompilers and renders with Vulkan, handing each frame to the frontend through memory, or with OpenGL into the frontend's own context. Needs the PS3 system software (PS3UPDAT.PUP) in the system directory. Save states are not supported.
